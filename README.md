# Universal Kinematics

Public source repository for the Universal Kinematics Skyrim plugin and its public SDK headers.

## Build

Requires Visual Studio 2022, CMake, vcpkg, and CommonLibSSE-NG. Configure with the supplied CMake preset and build the plugin target.

Build outputs, dependency installations, and source archive bundles are not included.
